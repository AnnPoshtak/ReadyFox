# 🦊 ReadyFox — Інтерактивна освітня платформа 🇺🇦

**ReadyFox** — це сучасна та 100% безкоштовна платформа, створена для того, щоб зробити процес навчання простим, безкоштовним та інтерактивним для кожного українського вчителя, викладача та студента.

Освіта не повинна сприйматися як примус чи привід для хвилювання — вона має захоплювати, тримати в тонусі та викликати щирий азарт!

---

## ✨ Основні можливості

* ⚡ **Створення квізів за 2 хвилини:** зручний інструмент для швидкої перевірки знань без зайвої бюрократії.
* 📱 **Миттєвий вхід для студентів:** приєднання до гри за 2 секунди за 6-значним кодом з будь-якого пристрою.
* 🎮 **Навчання через гру:** прості ігрові механіки, які перетворюють монотонні лекції та контрольні на азартний процес.
* 🇺🇦 **Зроблено в Україні:** розроблено з думкою про українські школи, університети, коледжі та освітні хаби.
* 🎁 **100% безкоштовно:** без пейволів, обмежень на кількість гравців у кімнаті чи прихованих "преміум-функцій".

---

## 🛠 Технологічний стек

### Frontend
* **Мова та збірка:** React 19, TypeScript, Vite
* **Маршрутизація:** React Router v7
* **Стилізація та іконки:** Tailwind CSS v4, Lucide React
* **Анімації:** Lottie (Lottie React / Player)
* **Форми та сповіщення:** React Hook Form, Sonner
* **HTTP-клієнт:** Axios

### Backend
* **Фреймворк та мова:** NestJS, TypeScript
* **База даних та ORM:** PostgreSQL, TypeORM
* **Аутентифікація:** Passport.js (JWT, Google OAuth 2.0, Local), Bcrypt
* **Валідація та DTO:** Class Validator, Class Transformer
* **Документація API:** Swagger (`@nestjs/swagger`)
* **Тестування:** Jest, Supertest
