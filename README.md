# 🦊 ReadyFox — Інтерактивна освітня платформа 🇺🇦

**ReadyFox** — це сучасна та 100% безкоштовна платформа, створена для того, щоб зробити процес навчання простим, безкоштовним та інтерактивним для кожного українського вчителя, викладача та студента.

Освіта не повинна сприйматися як примус чи привід для хвилювання — вона має захоплювати, тримати в тонусі та викликати щирий азарт!

---

## ✨ Основні можливості

* ⚡ **Створення квізів за 2 хвилини:** зручний інструмент для швидкої перевірки знань без зайвої бюрократії.
* 📱 **Миттєвий вхід для студентів:** приєднання до гри за 2 секунди за 6-значним кодом з будь-якого пристрою.
* 🎮 **Навчання через гру:** прості ігрові механіки, які перетворюють монотонні лекції та контрольні на азартний процес.
* 🇺🇦 **Зроблено в Україні:** розроблено з думкою про українські школи, університети, коледжі та освітні хаби.
* 🎁 **100% безкоштовно:** без пейволів, обмежень на кількість гравців у кімнаті чи прихованих "преміум-функцій".

## 🛠 Технологічний стек

### Frontend
* **Мова та збірка:** React 19, TypeScript, Vite
* **Маршрутизація:** React Router v7
* **Стилізація та іконки:** Tailwind CSS v4, Lucide React
* **Анімації:** Lottie (Lottie React / Player)
* **Форми та сповіщення:** React Hook Form, Sonner
* **HTTP-клієнт:** Axios

### Backend
* **Фреймворк та мова:** NestJS, TypeScript
* **База даних та ORM:** PostgreSQL, TypeORM
* **Аутентифікація:** Passport.js (JWT, Google OAuth 2.0, Local), Bcrypt
* **Валідація та DTO:** Class Validator, Class Transformer
* **Документація API:** Swagger (`@nestjs/swagger`)
* **Тестування:** Jest, Supertest

## Запуск проєкту

### Ручне встановлення

#### 1. Налаштування змінних середовища

Перед запуском проєкту створіть файл `.env` у кореневій директорії проєкту на основі `.env.example`:

```bash
cp .env.example .env
```

Заповніть файл `.env` відповідними значеннями.

#### 2. Опис змінних середовища

| Змінна | Опис |
|---|---|
| `PORT` | Порт, на якому працює backend-сервер |
| `JWT_SECRET` | Секретний ключ для підпису токенів доступу |
| `JWT_EXPIRATION` | Час дії токена доступу |
| `JWT_REFRESH_SECRET` | Секретний ключ для підпису токенів оновлення |
| `JWT_REFRESH_EXPIRATION` | Час дії токена оновлення |
| `GOOGLE_CLIENT_ID` | Ідентифікатор клієнта Google OAuth2 |
| `GOOGLE_CLIENT_SECRET` | Секрет клієнта Google OAuth2 |
| `GOOGLE_CALLBACK_URL` | URL-адреса для повернення після автентифікації через Google |
| `DB_HOST` | Адреса сервера бази даних |
| `DB_PORT` | Порт PostgreSQL |
| `DB_USERNAME` | Ім'я користувача бази даних |
| `DB_PASSWORD` | Пароль користувача бази даних |
| `DB_NAME` | Назва бази даних |
| `FRONTEND_URL` | URL-адреса frontend-застосунку |
| `VITE_BACKEND_URL` | URL-адреса API backend |

**Примітки:**
- Замініть усі шаблонні значення на власні.
- Налаштуйте облікові дані Google OAuth2 у [Google Cloud Console](https://console.cloud.google.com/).
- Переконайтеся, що PostgreSQL запущений, а необхідну базу даних створено.
- Використовуйте надійні та унікальні секретні ключі для JWT.
- Не додавайте файл `.env` із реальними секретами до репозиторію.

#### 3. Встановлення та запуск backend

Перейдіть до директорії `backend`, встановіть залежності, виконайте міграції бази даних і запустіть сервер:

```bash
cd backend
npm install
npm run migration:run
npm run dev
```

#### 4. Встановлення та запуск frontend

Відкрийте окремий термінал і виконайте такі команди:

```bash
cd frontend
npm install
npm run dev
```

Після запуску обох частин на сайт можна буде зайти за посиланням http://localhost:5173
